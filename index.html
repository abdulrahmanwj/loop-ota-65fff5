Install Loop

First delete the old Loop (iPhone will not replace a TestFlight app). Your settings come back from Nightscout with “Import Saved Settings”. Follow the checklist from Abdulrahman.

  1. Tap Install Loop, then tap Install on the popup.
  2. Go to the Home Screen and wait until the Loop icon finishes loading (1–3 min).
  3. If you see “Developer Mode Required”: tap OK → Settings → Privacy & Security → bottom → Developer Mode ON → Restart → confirm Turn On. (If it is not listed, turn off Screen Time → Content & Privacy Restrictions first.)
  4. Open Loop → set up Nightscout → tap Import Saved Settings.
  5. Then add the CGM and pair a new pod.
  1. احذف Loop القديم أولاً (الآيفون لا يستبدل نسخة TestFlight)، ثم افتح هذه الصفحة في Safari واضغط Install Loop ثم Install.
  2. ارجع للشاشة الرئيسية وانتظر حتى تكتمل أيقونة Loop (من دقيقة إلى ٣ دقائق).
  3. إذا ظهرت رسالة “Developer Mode Required”: اضغط OK ثم Settings → Privacy & Security → آخر الصفحة → فعّل Developer Mode → Restart → ثم Turn On. (إذا لم يظهر الخيار، أوقف Screen Time → Content & Privacy Restrictions مؤقتاً.)
  4. افتح Loop → أضف Nightscout → اضغط Import Saved Settings.
  5. ثم أضف جهاز السكر (CGM) واقرن بود جديد.
